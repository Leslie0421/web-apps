# 东亚精细排版实施计划（web-apps）

## 目标

在文档编辑器原生界面中提供东亚精细排版设置，并只调用 `sdkjs` 的标准属性 API，不在界面层模拟字距、行距或插入空格。

本仓库负责：

- 中文字体和西文字体分别选择。
- 段落高级设置中的四个东亚排版开关。
- 页面设置中的每页行数、每行字符数和文档网格类型。
- 多选混合状态、无权限状态和不同编辑模式下的交互。

## 依赖条件

- W1 依赖 `sdkjs` S1 的分字体槽位 API。
- W2 依赖 `sdkjs` S2，并在 S3/S4/S5 的排版实现完成后开放对应开关。
- W3 依赖 `sdkjs` S6 的节属性和网格换算 API。
- 在底层 API 未就绪时不得用已有单字体、字符间距或固定行距 API 模拟。

## 功能拆分和交付顺序

### W0：交互基线和兼容设计

- 对照 Microsoft Word、WPS 的字体、段落和页面设置界面制作交互清单。
- 明确设置作用域：当前选区、当前段落、当前节或整篇文档。
- 设计 `true / false / mixed / inherited` 四类状态的显示规则。
- 保持现有简化设置不变，高级能力放入可发现的高级区域。

验收：交互稿能够表达属性作用域和混合状态，不会把节属性误当成全文属性。

### W1：中文字体和西文字体

- 在字体高级设置中增加“中文字体”和“西文字体”。
- 中文字体写入 `eastAsia`；西文字体同时写入 `ascii/hAnsi`。
- 对复杂文字字体保持现有值，不因修改中西文字体而重置。
- 多选文字字体不一致时显示混合状态，用户选择后只覆盖目标槽位。
- 字体缺失时保持文件中的字体名并显示替代状态。

验收：选区内中文和英文分别改变字体，另一字体槽位不受影响。

### W2：段落高级东亚排版设置

- 在段落高级设置中增加：
  - 按中西文习惯控制首尾字符。
  - 允许标点溢出边界。
  - 自动调整中文与西文的间距。
  - 自动调整中文与数字的间距。
- 使用复选框混合态表示多段落不同值。
- 区分“继承样式”与“直接设置”，避免打开对话框后无操作也写入直接格式。
- 每个开关独立提交和测试；底层排版功能未发布时保持隐藏或受特性开关控制。

验收：设置、取消、撤销、重做和重新打开对话框的状态一致。

### W3：文档网格页面设置

- 在页面设置中增加网格模式：无网格、只指定行网格、指定行和字符网格、字符对齐网格。
- 提供“每页行数”和“每行字符数”输入，由 `sdkjs` 根据纸张、页边距、正文区域和基准字号换算 pitch。
- 明确设置作用域为当前节，并提供“应用于本节/所选节/整篇文档”的入口；整篇应用由编辑器逐节设置，不删除分节符。
- 当页边距、纸张方向、字号或网格数改变时展示实时预览和有效范围校验。
- 对不适用的组合给出解释，例如固定行距、分栏和表格可能覆盖或限制网格效果。

验收：分节文档可以保留不同网格；修改当前节不会改变其他节。

### W4：集成回归和可用性收口

- 验证只读、审阅、协作、桌面、嵌入式和移动端模式。
- 验证中文、英文和混合语言界面文案。
- 验证高 DPI、窄窗口、键盘导航和无障碍标签。
- 对 Word/WPS 样本文档执行打开、查看、修改、保存和再次打开测试。

## 预计涉及区域

- 文档编辑器字体设置及高级字体对话框。
- 段落高级设置对话框及其 ViewModel。
- 页面设置/页边距对话框及节属性 ViewModel。
- 本地化资源、自动化 UI 测试和截图基线。

具体文件在 W0 代码勘察完成后写入阶段记录，避免在 API 尚未确定前绑定错误组件。

## 测试要求

- 每个设置项具有 UI 单测或自动化交互测试。
- 多选混合值、样式继承、撤销重做和重新打开文档必须覆盖。
- 页面设置测试必须包含多节文档，且不能删除或合并用户已有分节符。
- 验证未安装字体、主题字体和字体替代提示。
- 执行仓库既有 lint、单元测试、构建和 `git diff --check`。

## 提交策略

- W0、W1、W2、W3、W4 分开提交。
- W2 中四个开关可以共享对话框骨架，但按底层能力逐个启用，避免一个未完成算法阻塞其他功能。
- 每阶段完成后更新 `docs/CHANGELOG.md`，记录对应 `sdkjs` API 和提交。

## 暂不纳入

- 业务项目专用测试侧栏。
- 用普通字距、行距模拟文档网格。
- 修改或删除现有分节符来实现“整篇应用”。
